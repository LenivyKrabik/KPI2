# Актори

### Користувачі:

- **Гість:** користувач без акаунту. Може лише зареєструватися
- **Зареєстрований користувач:** користувач з аккаунтом, проте без прав дослідника. Може проходити дослідження, але не створювати їх
- **Дослідник:** користувач з акаунтом, може все те що і звичайний користувач, а також здатен створювати дослідження та керувати ними.

### Системи та сервіси:

- **Парсер даних перед подачею:** система яка перетворює сирі дані з бази даних в певний формат даних при експорті даних, який був би зручніший досліднику для подальшої роботи

# Критерії прийому

- Перевірка вимог EARS на двозначність
- Звірити акторів і сутності з моделлю даних (не враховуючи акторів які є "базовим класом", як User)
- Перевірка чи всі вимоги покриті, а якщо ні то пояснення чому
- User stories має широке покриття різних варіантів як успіхів так і провалів use case сценаріїв
