# EARS requirements

---

## Functional

#### REQ-001 - Account creation

- User CAN register an account

#### REQ-002 - Researcher account

- User CAN improve account to researcher status

#### REQ-003 - Account deletion

- User CAN delete their account

#### REQ-004 - Account editting

- User CAN edit information about their account

#### REQ-005 - Form completion

- User CAN complete form BUT only once

#### REQ-006 - Research creation

- Researcher CAN create research

#### REQ-007 - Form creation

- Researcher CAN create form BUT only for their research

#### REQ-008 - Data export

- Researcher CAN export data from research in .xlsx, .csv or .json formats BUT only from their research

#### REQ-009 - Data saving

- System SHALL save form answers

#### REQ-015 - Research editting

- Researcher CAN edit their research information, which includes deletion and closing new answers acception

#### REQ-016 - Form editting

- Researcher CAN edit their researches forms, which includes deletion

---

## Non-functional

### Accessibility

#### REQ-010 - Visual impairments

- Interface SHALL include features to assist people with visual impairments

#### REQ-011 - Localization

- Interface SHALL support localization with different languages

### User-friendly interface

#### REQ-012 - Simplisity

- User SHALL be able to find and complete researches not leaving the main page

### Security

#### REQ-013 - Data falsification

- System SHALL save from data falsification

#### REQ-014 - Anonimity

- User SHALL NOT be traceable to their answers
