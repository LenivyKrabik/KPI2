# Лабораторна робот №1

## EasyData

### Опис:

- Платформа для опитування людей для наукових досліджень. На ній, люди добровільно видялють частку свого часу _заради науки_.

### Можливості:

- Дозволяє дослідникам створювати опитування
- Дозволяє проходити опитування звичайним користувачам
- Дає дослідникам можливість експортувати данні їх опитувань
- Дає змогу, коли дослідження буде готове, подивитися їх результати тим хто приймав участь
