# Використання UUIDv7

## Context and Problem Statement

Кожній сутності потрібен унікальний ідентифікатор. Який з варіантів краще всього обрати для цієї задачи?

## Considered Options

- Інкрементуючийся лічильник (int)
- UUIDv4
- UUIDv7

## Decision Outcome

Вирішено взяти для всіх id - UUIDv7. Він попросту краще та надійніше за UUIDv4. Тому сенсу брати його точно немає. А оскільки інкрементуючий лічильник може мати свої проблеми при розподілених системах та дозволяє гадати інший id просто зробивши + чи - до іншого (що дуже не добре), він теж відпадає.

## Results

- Плюс - гарантовані унікальні ID для кожної сутності
- Плюс - захист від легкої зміни id на інший, працюючий
- Мінус - id займає більше місця в пам'яті
