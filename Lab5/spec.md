Моя задача - розробити component diagram для проекту який я проектував всі минулі лаби.

# Компоненти

## UI

Frontend застосунку через який користувач виконує усі взаємодії

## Orcid OAuth

OAuth сервіс Orcid, через який відбуваєтсья підтвердження аккаунту дослідника

## Scopus

Сервіс scopus, через який ща допомогою пошти, або OrciID можна дізнатися ScopusID

## Router

Роутер який розподіляє трафік який приходить до бекенду

## OrcidServicee

Сервіс який відповідає за комунікацію з Orcid

## ScopusServicee

Сервіс який відповідає за комунікацію з Scopus

## AccountManagerService

Менедженр аккаунтів

## ResearchManagerService

Менеджер досліджень та їх форм

## Email provider

Сервіс для відправлення відправки листів (наприклад одноразових листів підтвердження)

## DB

Тяжко повірити, але це БД

# Критерії прийому

- Повна логіка (немає односторонніх з'єднань, самотніх компонентів і т.д.)
- Provided/required-інтерфейси, залежності
- Чітка межа системи, зовнішні інтеграції
- Кожен компонент/залежність трасується до попередніх моделей (дані, вимоги, взаємодія, процес)
