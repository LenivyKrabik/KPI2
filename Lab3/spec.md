# Наміри

Я хочу створити sequence diagram, яка б описала UC2 - підвищення звичайного аккаунта до дослідника

# Сутності

- **User:** Користувач зі звичайним аккаунтом (не дослідника)
- **Frontend:** Інтерфейс додатку
- **Backend:** Сервера сервісу
- **Orcid OAuth:** API Orcid для автентифікації через їх сервіс
- **Scopus Search API:** API Scopus'а, який дозволяє знайти Scopus ID якщо є корпорат пошта, або OrciID

# Критерії прийому

- Відповідність постановці завдання в класрумі
- Всі сутності присутні та приймають участь
- Звірити діаграму з використаннями в минулих лабах
